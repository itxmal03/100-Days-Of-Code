# Day 8 – Sort Each Row of a 2D Matrix

## Overview
Today we practiced sorting each row of a 2D matrix. The goal was to understand **row-wise sorting** and strengthen problem-solving logic step by step. This exercise also helped reinforce **insertion sort logic** applied in a real scenario (a matrix instead of a single array).

---

## Problem Statement
Given a 2D matrix, sort the elements **within each row** in ascending order. Each row should be independently sorted without affecting other rows.

### Example
**Input Matrix:**
```text
[
  [4, 3, 6],
  [11, 1, 12],
  [0, 2, -1]
]

**Output Matrix:**
[
  [3, 4, 6],
  [1, 11,12],
  [-1,0, 2]
]
