## 🧠 What I Worked On

### 1️⃣ XOR Operator – Finding a Unique Element

I practiced the classic problem:

> Find the unique element in an array where all other elements appear exactly twice.

**Core logic used:**
- `x ^ x = 0`
- `0 ^ y = y`
- XOR cancels duplicate values and keeps the unique one

This problem was first practiced in **C++** and then correctly translated into **Dart**, reinforcing that:
- Logic is language-independent
- Syntax changes, reasoning does not

---

### 2️⃣ C++ → Dart Translation

I converted:
- Static arrays → `List<int>`
- Range-based loops → Dart `for-in` loops
- Output statements → `print()`

This strengthened my understanding of:
- Cross-language problem solving
- Applying the same logic in different environments
- Dart-specific data structures

### 3️⃣ Attempted: Unique Consecutive Characters (Incomplete)

I started working on a problem involving **unique consecutive characters in a string**, but intentionally stopped midway.

This exposed an important issue:
- I began writing code **without fully defining the problem**
- I did not clearly decide:
  - Expected output
  - Comparison rules
  - Stopping conditions

Stopping early was the correct decision, as forcing code without clarity leads to confusion.
